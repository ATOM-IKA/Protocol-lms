# PROTOCOL LMS — План разработки

Цель: не «ещё одна СДО», а система, которая выглядит и работает **на голову выше** любой другой.
Стиль: **NEON GRID** — киберпанк, неон аква + кислотный лайм на индиго-чёрном, HUD-разметка, катакана-акценты, глитч и голографика. **Одна тема, финально.**
Порядок: сначала дизайн и весь функционал по страницам, безопасность и юр-блок — в конце.

---

## 0. Принципы (зафиксировано)

- **Палитра**: фон индиго-чёрный `#0B0D12`; неон-аква `#9FE8FF` (линии, метки, ссылки) + кислотный лайм `#BEEF8D` (кнопки, XP); глубокий тил `#3A745D` — приглушённый акцент.
- **Шрифты**: Unbounded (кибер-заголовки), Inter (текст), JetBrains Mono (метки/цифры/код), системный JP-стек для катакана-акцентов.
- **HUD-разметка**: моно-метки `// section`, hex-индексы `01 —`, срезанные углы (`clip-path`), угловые скобки, катакана.
- **Всё живое**: карточки показывают реальные данные, а не статичные числа.
- **Анимации**: глитч заголовков, скан-линии, голо-блик, «набегающие» цифры XP. Уважаем `prefers-reduced-motion`. Framer Motion.
- **Доступность**: контраст ≥ 4.5:1, клавиатура, ARIA, видимый фокус (аква).

## 1. Фирменные фичи (наш «почерк»)

Это то, что делает PROTOCOL узнаваемым:

1. **Цифровая ID-карта / генеративный аватар** — у каждого студента уникальная кибер-карта профиля: генеративный аватар (детерминирован по ID, у каждого свой) + опция заменить на фото, уровень, XP, ранг, катакана, голо-блик и скан-линия. Наша главная фишка.
2. **Command Palette `⌘K`** — терминал-навигация: мгновенный переход к курсу, уроку, действию.
3. **Живые карточки-дашборды** — у каждого курса: прогресс-кольцо, streak (серия дней), sparkline активности.
3. **Learning Graph** — годовая тепловая карта обучения (contribution-граф в лайме) в профиле.
4. **Signature-анимации** — decode/scramble заголовков, «набегающие» цифры XP, прочерчивание грид-линий.
5. **XP HUD** — постоянный индикатор опыта/уровня в шапке приложения с анимацией level-up.

## 6. Мульти-колледж (изоляция учебных заведений)

Ключевое требование: студент входит в рамках своего **учебного заведения** и видит **только его курсы**.

- Коллекция `institutions`: `id`, `name`, `short_name`, `logo`, `theme` (какая из 3 тем по умолчанию).
- У `users` — связь `institution`; у `courses` — связь `institution`.
- На входе: сначала выбор колледжа (поиск/список), затем `student_id` + пароль.
- Каталог и все запросы фильтруются по `institution` текущего пользователя (на сервере — правилами PocketBase, не только на клиенте).
- Плюс: тема оформления может подтягиваться из настроек колледжа.

## 7. Тема — единая NEON GRID (финально)

Ранняя идея с 3 темами **отменена** по вашему решению: одна сильная тема-личность вместо переключателя. Система тем (`ThemeProvider`, переключатель) убрана из кода.

**NEON GRID** — киберпанк с собственным лицом:
- Палитра: индиго-чёрный `#0B0D12` + неон-аква `#9FE8FF` + кислотный лайм `#BEEF8D` + тил `#3A745D`.
- Шрифты: Unbounded (заголовки), Inter (текст), JetBrains Mono (метки), системный JP-стек (катакана).
- Оформление: HUD-сетка, угловые скобки, срезанные углы (`clip-path`), hex-индексы, катакана, глитч заголовков, скан-линии, голо-блик.
- Ядро айдентики — **цифровая ID-карта** с генеративным аватаром (см. раздел 1).
