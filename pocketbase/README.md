# PROTOCOL — бэкенд PocketBase (с нуля)

Чистая, безопасная схема взамен старой. XP считается только на сервере,
курсы изолированы по колледжам, данные пользователей закрыты.

Целевая версия: **PocketBase v0.22+**. Проверить свою: `./pocketbase --version`.

## Состав

```
pocketbase/
├── SCHEMA.md                 — авторитетная спецификация (коллекции, поля, правила)
├── pb_migrations/
│   ├── 1690000000_protocol_init.js   — создаёт все коллекции при старте
│   ├── 1690000100_auth_identity.js   — student_id как поле входа
│   ├── 1690000200_submissions.js     — коллекция сдачи работ (текст + файлы)
│   ├── 1690000300_lesson_open.js     — поле open у урока (открытие преподавателем)
│   └── 1690000400_lesson_submission.js — поле submission у урока (приём работ)
├── pb_hooks/
│   └── main.pb.js            — сервер: XP-движок, оценки, защита полей, аудит
└── seed/
    ├── op16-content.mjs      — контент курса ОП.16 (3 раздела, 10 работ)
    └── seed-op16.mjs         — заливает курс в PocketBase под преподавателем
```

## Сид курса ОП.16

После запуска PocketBase и создания преподавателя выполните из корня проекта:

```
node pocketbase/seed/seed-op16.mjs <student_id_преподавателя> <пароль> [URL_PocketBase]
```

URL по умолчанию берётся из `.env` (`VITE_POCKETBASE_URL`) или `http://127.0.0.1:8090`.
Курс создаётся черновиком — откройте кабинет преподавателя и нажмите «Опубликовать».

## Установка

1. Скачайте PocketBase (v0.22+) с https://pocketbase.io/docs и распакуйте.
2. Скопируйте папки `pb_migrations/` и `pb_hooks/` **рядом** с бинарником `pocketbase`.
3. Запустите:

   ```bash
   ./pocketbase serve
   ```

   При первом старте применятся миграции (создадутся коллекции), подключатся хуки.
4. Откройте админку (адрес выведется в консоли, обычно `http://127.0.0.1:8090/_/`),
   создайте суперпользователя.

## Начальные данные (минимум для входа)

1. В коллекции **institutions** добавьте 1–2 колледжа (`name`, `short_name`).
2. В **users** заведите пользователя: `email`, пароль, `full_name`, `student_id`,
   `role` (`student`/`teacher`/`admin`), `institution` (выберите колледж).
   (Регистрация закрыта — пользователей создаёт админ.)
3. Преподаватель создаёт курсы (`owner` = его id, `institution` = его колледж,
   `status` = `published`), разделы и уроки.

## Проверка безопасности (быстро)

- Залогиньтесь студентом и попробуйте `PATCH /api/collections/users/records/<id>`
  с `{"xp": 999999}` — сервер откатит: XP не изменится (хук `guardUserFields`).
- Отметьте урок (`session_progress.completed = true`) — XP/level/rank у пользователя
  и `progress_percent` у enrollment пересчитаются автоматически.
- Студент другого колледжа не увидит чужие курсы в `GET /api/collections/courses/records`.

## Подключение фронтенда

В корне фронтенд-проекта в `.env`:

```
VITE_POCKETBASE_URL=http://127.0.0.1:8090
```

(для прод-сборки — адрес вашего PocketBase-сервера).

Клиент уже есть: `src/shared/api/pocketbase.ts`. Следующий блок работ —
перевод фронтенда со временных localStorage-сторов на реальные запросы к этим
коллекциям (сервисы + React Query), с сохранением текущего UI.

## Примечание про версию

Файлы написаны под современный JSVM-API PocketBase (v0.22+). В этой среде запустить
PocketBase нельзя, поэтому код не проверялся вживую — если ваша версия отличается по
API миграций/хуков, скиньте `--version`, и я подгоню синтаксис. Правила доступа
(самое важное для безопасности) в `SCHEMA.md` — версионно-независимы.
