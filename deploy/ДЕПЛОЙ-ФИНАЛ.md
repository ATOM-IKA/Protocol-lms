# PROTOCOL — деплой финальной версии (по шагам)

Сервер: `root@159.194.237.33` · Сайт: https://protocol-lms.ru
Проект локально: `E:\protocol-lms`

Все команды — по одной строке. Запускай в **PowerShell** (не в cmd), из любой папки — пути указаны полностью.

---

## 0. Если SSH не подключается («Connection timed out»)

1. Открой панель Beget → раздел VPS → твой сервер → кнопка **«Перезагрузить»**. Подожди 3–5 минут.
2. Проверь, что сайт открывается в браузере: https://protocol-lms.ru — если да, сервер жив.
3. В Beget проверь, что фаервол разрешает порт **22** (SSH).
4. Если снова таймаут — используй **веб-консоль (VNC)** в панели Beget: там SSH не нужен, команды из шагов 3–4 вводишь прямо в ней (без `ssh root@...`, только то, что в кавычках).

---

## 1. Собрать сайт локально

```
cd E:\protocol-lms
npm install
npm run build
```

После сборки появится папка `E:\protocol-lms\dist` — это и есть сайт.

---

## 2. Обновить бэкенд (база + логика: группы, валюта, уведомления, доска)

```
ssh root@159.194.237.33 "rm -rf /root/pb_migrations /root/pb_hooks"
scp -r E:\protocol-lms\pocketbase\pb_migrations root@159.194.237.33:/root/pb_migrations
scp -r E:\protocol-lms\pocketbase\pb_hooks root@159.194.237.33:/root/pb_hooks
ssh root@159.194.237.33 "systemctl restart pocketbase"
```

При рестарте PocketBase сам применит новые миграции (в т.ч. `1690000800_gamification.js`).

Проверить, что бэкенд поднялся:

```
ssh root@159.194.237.33 "systemctl status pocketbase --no-pager"
```

Должно быть `active (running)`.

---

## 3. Обновить сайт (фронтенд)

```
ssh root@159.194.237.33 "rm -rf /var/www/protocol-lms/dist"
scp -r E:\protocol-lms\dist root@159.194.237.33:/var/www/protocol-lms/dist
```

nginx перезапускать не нужно — он просто отдаёт файлы из этой папки.

---

## 4. Проверить

Открой https://protocol-lms.ru и нажми **Ctrl+F5** (сброс кэша).

Должно работать: портал на входе, вход по 3 ролям, группы, монеты, уведомления (колокольчик), доска заданий, экспорт аудита в админке.

---

## 5. Разово настроить супер-админа (без SSH, через админку PocketBase)

1. Открой https://protocol-lms.ru/_/ и войди как администратор PocketBase.
2. Collections → **users** → найди свой аккаунт → поставь `role = superadmin`, поле `institution` оставь **пустым** (супер-админ не привязан к колледжу) → сохрани.
3. Если в списке значений `role` нет `superadmin` — открой поле `role`, добавь значение `superadmin`, сохрани, потом повтори п.2.
