# PROTOCOL — аудит системы

Дата: июль 2026. Полная статическая проверка кода + логический разбор.

## Что проверено (автоматически)
- **TypeScript (`tsc -b`)** — 0 ошибок.
- **Паритет локалей ru/en** — наборы ключей идентичны, расхождений 0.
- **Все 12 миграций PocketBase** — синтаксис валиден, порядок зависимостей корректный.
- **Серверные хуки (`main.pb.js`)** — синтаксис валиден.
- **Использование i18n** — 0 отсутствующих ключей; все динамические префиксы (`auth.role_*`, `course.type_*`, `board.empty_*`, `quiz.type_*`, `ach.*`) имеют полный набор вариантов.
- **Прод-сборка (`vite build`)** — не запускается в песочнице (нет нативного модуля rollup для Linux); на вашем ПК под Windows собирается штатно, типы уже покрыты `tsc`.

## Найдено и исправлено
- Опыт за задания с доски и тесты теперь попадает в общий `users.xp` → рейтинг и профиль показывают одинаковый опыт.
- Куратор группы виден в профиле студента (привязка студент → группа → куратор).
- Баланс монет обновляется на странице профиля/кабинета (раньше брался только из данных входа).
- Устойчивость к кэшу: авто-перезагрузка при устаревшей сборке + no-store для index.html.

## Замечания (низкий приоритет, на будущее)
1. **Монеты админов** пересчитываются только при событии; без действий баланс может оставаться 0. Можно добавить пересчёт при создании/удалении пользователей.
2. **Правильные ответы тестов** технически доступны на чтение студенту (оценку подделать нельзя — считает сервер). Для повышенной защиты позже вынести выдачу вопросов в отдельный эндпоинт без правильных ответов.
3. **Лидерборд** наполняется после первой активности студента (первый опыт). Неактивные студенты появятся после первого действия.
4. **Магазин** (в планах) изменит модель монет на «заработано − потрачено» — пересчёт будет вычитать покупки.
5. **Мобильное меню** стало насыщенным (до ~9 пунктов у преподавателя) — со временем стоит вынести часть в «Ещё».

## Ручной тест после общего деплоя (чек-лист)
Проверить под каждой ролью:

**Студент:** вход → лендинг СДО → курсы, запись на курс, прохождение урока, сдача работы; доска (взять/отказаться/вернуть); тест (прохождение, результат, монеты+опыт); профиль (группа, куратор, посещаемость, монеты); рейтинг и достижения; уведомления (оценка, приём задания, открытие урока); возврат на портал/лендинг без повторного входа.

**Преподаватель:** создание курса/уроков, открытие урока, проверка и оценка работ; доска (публикация, приём/отклонение); тесты (создание, вопросы, публикация); журнал (оценки + посещаемость, экспорт Excel); уведомления (новая работа, выполнение/отказ по доске); монеты за успехи студентов.

**Админ/супер-админ:** пользователи (создание, роль, группа, импорт), группы и кураторы, заведения, модерация курсов, аудит + экспорт в Excel; супер-админ без привязки к колледжу.
