# PROTOCOL LMS — как запустить

Проект лежит в `E:\protocol-lms`. Ниже — пошаговый запуск на Windows.

## 1. Установить Node.js

Нужен **Node.js 20+** (LTS). Проверьте в терминале:

```bash
node -v
npm -v
```

Если нет — скачайте LTS с https://nodejs.org и установите.

## 2. Открыть папку проекта

В терминале (PowerShell или встроенный терминал VS Code):

```powershell
cd E:\protocol-lms
```

## 3. Установить зависимости

```powershell
npm install
```

Скачает React, Vite, Framer Motion, шрифты и всё остальное в папку `node_modules`.
Делается один раз (и после изменений в `package.json`).

## 4. Настроить адрес PocketBase

Скопируйте пример окружения и укажите URL вашего PocketBase:

```powershell
copy .env.example .env
```

Откройте `.env` и впишите адрес (по умолчанию локальный PocketBase):

```
VITE_POCKETBASE_URL=http://127.0.0.1:8090
```

## 5. Запустить в режиме разработки

```powershell
npm run dev
```

Vite поднимет сайт на **http://localhost:5173** — откройте в браузере.
Изменения в коде применяются мгновенно (hot reload).

## 6. Полезные команды

```powershell
npm run build     # сборка в папку dist (проверка ошибок TypeScript)
npm run preview   # посмотреть собранную версию
npm run lint      # проверка ESLint
npm run format    # автоформат Prettier
```

## Если что-то не работает

- **`node`/`npm` не найдены** — переустановите Node.js и перезапустите терминал.
- **Порт 5173 занят** — Vite сам предложит другой порт, либо закройте прежний процесс.
- **Ошибка про VITE_POCKETBASE_URL** — не создан `.env` (см. шаг 4).
- **Белый экран** — откройте консоль браузера (F12) и пришлите мне текст ошибки.
